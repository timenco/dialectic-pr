## [Unreleased]

### Changed
- **3-Step Dialectic Output**: 리뷰 출력이 STEP 1 (Review Agent) → STEP 2 (Dev Agent Challenge) → STEP 3 (Final Consensus) 구조로 변경
- **Review Format**: 📊 메트릭 불릿 리스트, 📋 Executive Summary, 🔴/🟡 이슈 분류, ✅ 긍정적인 점, 📊 Final Verdict 포함
- **Default Model**: `claude-sonnet-4-20250514` → `claude-opus-4-6`
- **Footer**: 모델명 표시 (`Generated by Claude Opus 4.6 · Dialectic PR Review`)
- **Flag Labels**: 한국어 라벨 (`🧪 테스트 포함`, `📐 스키마`, `⚙️ 설정만`)
- **Consensus JSON**: `{ consensus_completed, agreed_issues, rejected_issues, verdict, false_positive_rate }` 스키마로 변경

### Added
- `file-classifier.ts` — 파일 분류 로직 단일 소스 (`isSourceFile`, `isTestFile`, `isSchemaFile`, `isConfigFile`)
- `CRITICAL_MODULE_PATH` 상수 — regex 조합 안전성 확보
- `STRATEGY_THRESHOLDS` 상수 — PR 크기별 전략 임계값 중앙 관리
- `DEFAULT_MODEL` 상수 — 모델명 단일 지점 관리
- `formatModelName()` — 모델 ID → 표시명 변환 (`claude-opus-4-6` → `Claude Opus 4.6`)

### Fixed
- 에러 로그에서 credential 누출 방지 (`safeError()` 래퍼)
- `process.env` credential 오염 방지
- regex `.source` 조합 취약성 제거 (`CRITICAL_MODULE_PATH` 문자열 상수 기반)

### Security
- `PrivacyGuard`: diff 내 시크릿 자동 감지
- `ExcludeFilter`: 민감 파일 자동 제외 (`.env`, credentials 등)
- 에러 메시지 마스킹으로 API 키 누출 방지

## [1.0.0] - 2026-01-04

### 🎉 Phase 1 Complete: Core Engine

Initial release of Dialectic PR — AI Code Reviewer for TypeScript projects.

#### Core Features
- **Consensus Review Engine**: Single-call multi-persona consensus review system
- **Framework Detection**: Automatic detection of NestJS, Next.js, React, Express projects
- **Smart File Filtering**: Priority-based file review with token budget optimization
- **False Positive Defense**: 38 built-in patterns to reduce AI hallucinations

#### Claude API Optimizations
- **Prompt Caching**: 90% cost reduction on repeated reviews
- **Structured Output**: JSON block extraction for reliable parsing

#### Configuration
- `CLAUDE.md` 자동 감지 (프로젝트 컨텍스트)
- `.github/review-guardrails.json` 자동 감지 (프로젝트 FP 패턴)
- `.github/dialectic-pr.json` 메인 설정

#### Testing
- 104 tests (7 suites, 100% passing)
- Integration + unit test coverage

### Technical Highlights

- **30 modules**, ~5,800 lines of TypeScript
- **5 frameworks** supported (NestJS, Next.js, React, Express, Vanilla)
- **38 built-in FP patterns** across 9 categories
- **Prompt Caching** for cost optimization
- **Security-first** with sensitive file exclusion and secret detection
